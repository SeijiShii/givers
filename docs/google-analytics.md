# Google Analytics 4 (GA4) 導入ガイド

## 概要

GIVErS では Google Analytics 4 (GA4) を使ってサイトのアクセス解析を行う。
GA4 のトラッキングスクリプトは `BaseLayout.astro` の `<head>` に埋め込まれており、環境変数 `PUBLIC_GA_MEASUREMENT_ID` が設定されている場合のみ有効になる。

## GA4 の仕組み

1. ユーザーがページにアクセスすると、`gtag.js` スクリプトが読み込まれる
2. `gtag('config', 'G-XXXXXXXXXX')` により、ページビューが自動的に Google に送信される
3. Google Analytics のダッシュボードでリアルタイム・過去のデータを確認できる

GA4 はイベントベースの計測モデルを採用しており、以下が自動的に収集される：

| イベント | 内容 |
|---------|------|
| `page_view` | ページ閲覧 |
| `scroll` | ページの 90% までスクロール |
| `click` | 外部リンクのクリック |
| `session_start` | セッション開始 |
| `first_visit` | 初回訪問 |

## 測定 ID の取得手順

1. [Google Analytics](https://analytics.google.com/) にアクセス（Google アカウントでログイン）
2. 左下の **管理**（歯車アイコン）をクリック
3. **「+ アカウントを作成」** をクリック
   - アカウント名: `GIVErS`（任意）
   - データ共有設定: デフォルトのまま → **次へ**
4. **プロパティを作成**
   - プロパティ名: `GIVErS`
   - レポートのタイムゾーン: `日本`
   - 通貨: `日本円（JPY）`
   - → **次へ** → ビジネス情報を適宜入力 → **作成**
5. **データストリームを設定**
   - プラットフォーム: **ウェブ** を選択
   - ウェブサイトの URL: `givers.work`
   - ストリーム名: `GIVErS Web`
   - → **ストリームを作成**
6. 作成後の画面に表示される **測定 ID**（`G-XXXXXXXXXX` 形式）をコピー

## 環境変数の設定

### 開発環境

トラッキング不要のため、設定しない（未設定時はスクリプトが出力されない）。

### 本番環境

`frontend/.env.prod` に測定 ID を設定：

```
PUBLIC_GA_MEASUREMENT_ID=G-XXXXXXXXXX
```

設定後にデプロイすればトラッキングが開始される。

## ダッシュボードの見方

[Google Analytics](https://analytics.google.com/) にログイン後、左メニューから各レポートにアクセスできる。

### よく使うレポート

| 目的 | メニュー | 見られるデータ |
|------|---------|--------------|
| 今のアクセス状況 | **レポート → リアルタイム** | 現在サイトにいるユーザー数、閲覧中のページ |
| アクセス数の推移 | **レポート → エンゲージメント → ページとスクリーン** | ページ別の表示回数・ユーザー数・平均滞在時間 |
| 全体の概要 | **レポート → レポートのスナップショット** | ユーザー数、セッション数、ページビュー数のサマリー |
| ユーザーの属性 | **レポート → ユーザー属性 → 概要** | 国・市区町村・言語・年齢・性別 |
| 流入経路 | **レポート → 集客 → トラフィック獲得** | どこからサイトに来たか（検索、SNS、直接アクセス等） |
| デバイス | **レポート → テクノロジー → 概要** | PC / モバイル / タブレットの比率、ブラウザ、OS |

### GIVErS で特に見るべき指標

- **ページビュー数（表示回数）**: サイト全体・ページ別のアクセス数
- **ユーザー数**: サイトに訪れたユニークユーザーの数
- **セッション数**: 訪問回数（1人が複数回訪問すれば複数カウント）
- **平均エンゲージメント時間**: ユーザーがページを実際に見ていた時間
- **ページ別ランキング**: どのプロジェクトページが人気かを把握

### 期間の変更

各レポート画面の右上にある日付セレクターで、集計期間を変更できる（過去7日、28日、90日、カスタム範囲など）。

## 動作確認

1. **本番デプロイ後**: Google Analytics の **リアルタイム** レポートでアクセスが表示されることを確認
2. **ブラウザ開発者ツール**: Network タブで `gtag/js` へのリクエストが発生していることを確認
3. **Tag Assistant**: [Google Tag Assistant](https://tagassistant.google.com/) でタグの動作を検証
