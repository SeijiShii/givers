# 感謝メッセージ機能 仕様書

## 概要

プロジェクトオーナーがカスタム感謝メッセージを設定し、寄付者が決済完了後にプロジェクトページへ戻った際にモーダルダイアログとして表示する機能。

## ユーザーストーリー

### プロジェクトオーナー
- プロジェクト作成時に感謝メッセージを入力できる
- プロジェクト編集画面で感謝メッセージを変更できる
- 感謝メッセージは任意項目（未設定でも可）

### 寄付者
- Stripe 決済完了後、プロジェクトページに戻るとモーダルダイアログが表示される
- オーナーがカスタムメッセージを設定していればそれが表示される
- 未設定の場合はデフォルトメッセージ「ご支援ありがとうございます！」が表示される
- モーダルは閉じるボタンで明示的に閉じる

## データモデル変更

### projects テーブル

| カラム | 型 | デフォルト | 説明 |
|--------|------|------------|------|
| thank_you_message | TEXT | '' | 寄付者に表示する感謝メッセージ |

マイグレーション: `026_add_thank_you_message`

## API 変更

### POST /api/projects（プロジェクト作成）

リクエストボディに `thank_you_message` フィールドを追加（任意）。

```json
{
  "name": "プロジェクト名",
  "thank_you_message": "ご支援ありがとうございます！皆様のおかげで..."
}
```

### PUT /api/projects/:id（プロジェクト更新）

リクエストボディに `thank_you_message` フィールドを追加（任意）。
送信しない場合は既存値を維持する（部分更新対応）。

### GET /api/projects/:id（プロジェクト取得）

レスポンスに `thank_you_message` フィールドを追加。

```json
{
  "id": "xxx",
  "name": "プロジェクト名",
  "thank_you_message": "ご支援ありがとうございます！",
  ...
}
```

## UI 仕様

### プロジェクトフォーム（作成・編集）

- シェアメッセージ欄の直後に配置
- ラベル: 「感謝メッセージ」
- プレースホルダー: 「寄付後に表示されるメッセージを入力」
- ヒント: 「寄付者が決済完了後にこのメッセージが表示されます」
- textarea（2行）

### 感謝モーダルダイアログ

- **トリガー**: URL パラメータに `donated` または `session_id` が含まれる場合
- **表示位置**: 画面中央、半透明オーバーレイ付き
- **内容**:
  - タイトル: 既存 i18n キー `projects.thankYouTitle`（「ありがとうございます！」）
  - 本文: プロジェクトの `thank_you_message`（未設定時はデフォルトメッセージ）
  - 閉じるボタン
- **スタイル**: 緑系（`--color-primary`）のアクセントカラー
- **z-index**: 1100（ナビゲーションメニューと同レベル）
