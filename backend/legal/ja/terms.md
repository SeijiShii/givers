# 利用規約

最終更新日：2026年5月31日

本利用規約（以下「本規約」）は、QUADii（以下「運営者」）が提供する GIVErS（以下「本サービス」）の利用条件を定めるものです。本サービスをご利用いただく前に、本規約をよくお読みください。本サービスを利用した時点で、本規約に同意したものとみなします。

## 第1条（サービスの概要）

本サービスは、プロジェクトオーナー（作り手）と寄付者をつなぐ寄付プラットフォームです。運営者は寄付金から運営手数料を徴収せず、寄付金は Stripe, Inc. が提供する Stripe Connect を通じてプロジェクトオーナーの Stripe アカウントに直接入金されます。決済に伴う Stripe の決済処理手数料の取り扱いについては第4条に定めます。

## 第2条（利用資格）

本サービスは、日本国内外を問わず個人・法人がご利用いただけます。ただし、18歳未満の方は保護者の同意を得た上でご利用ください。

## 第3条（アカウント）

1. アカウント登録は任意です。アカウントなしでも単発寄付が可能です。
2. 登録情報は正確かつ最新の状態に保ってください。
3. アカウントの認証情報は第三者に開示しないでください。
4. アカウントの不正利用が疑われる場合は速やかにご連絡ください。

## 第4条（寄付・決済について）

1. 寄付の決済は Stripe, Inc.（以下「Stripe」）が提供する決済サービス（Stripe Connect を含む）を通じて行われます。決済の利用にあたっては、Stripe が定める規約（[Stripe サービス規約](https://stripe.com/jp/legal/ssa)）が適用されます。
2. 寄付金はプロジェクトオーナーの Stripe アカウントに直接入金されます。運営者は寄付金を預からず、資金の経由地にはなりません。ただし、返金処理は本サービスが Stripe を通じて補助します。
3. 寄付の返金は、プロジェクトオーナーまたは寄付者がプラットフォーム上から手続きできます。返金は全額返金のみとし、部分返金には対応しません。返金処理には数営業日かかる場合があります。
4. 定期寄付（継続課金）について
   - 課金は申込時に選択した周期（例：毎月）で、選択した金額が自動的に継続して決済されます。
   - 各回の決済金額・課金周期・次回課金日は、申込時の最終確認画面およびログイン後の管理画面（マイページ）に表示されます。
   - 解約はいつでも、ログイン後の管理画面（マイページ）からお手続きいただけます。解約すると次回以降の課金が停止します。次回課金日の前までに解約手続きを完了してください。一時停止・金額変更も同管理画面から行えます。
   - 既に決済済みの各回の寄付については、前項に従い個別に返金を申請できます。
5. チャージバック・異議申立てについて
   - 寄付者がカード会社等を通じて支払いの取消し（チャージバック）を申し立てた場合、当該寄付に係る返金・手数料の負担は、Stripe の定めおよびプロジェクトオーナーとの間で処理されます。運営者は寄付金を預からないため、原則として当該負担を負いません。
6. 寄付金控除（税額控除）については、各プロジェクトの案内および税理士・弁護士等の専門家にご確認ください。運営者は税務上の効果を保証しません。

## 第5条（プロジェクトオーナーの義務）

1. プロジェクト情報は正確に記載し、誤解を招く表現を避けてください。
2. 受け取った寄付金はプロジェクトの目的に沿って使用してください。
3. 支援者への情報開示・進捗報告に誠実に対応してください。
4. Stripe が定める[禁止・制限される事業](https://stripe.com/jp/restricted-businesses)に該当する商材・活動のために本サービスを利用してはなりません。
5. プロジェクトオーナーが物品・役務等のリターンを提供する場合、特定商取引法その他の適用法令に基づく表示義務は当該プロジェクトオーナーが負うものとし、運営者はこれを保証しません。

## 第6条（禁止事項）

本サービスにおいて、以下の行為を禁止します。

- 虚偽の情報を記載・送信する行為
- 詐欺的なプロジェクトを掲載する行為
- Stripe が定める禁止・制限される事業に該当する利用（[一覧](https://stripe.com/jp/restricted-businesses)）
- 本サービスへの不正アクセス・妨害行為
- 他のユーザーへの嫌がらせ・差別的言動
- 法令または公序良俗に反する行為
